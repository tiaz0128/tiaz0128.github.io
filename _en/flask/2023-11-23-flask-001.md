## Prologue

To deliver notification messages to clients periodically from Flask, let's implement them with **Server-Sent Events (SSE)**.

## Sockets vs SSE

The reason I chose SSE over sockets is simple. For notifications, the server periodically sends data to the client, and only when there's something new does it need to say

> You've got a new notification!

The client can then re-render with the data it received or call an API to fetch the new notifications, so I didn't think two-way communication with the client was necessary. Here are a few characteristics of SSE.

1. **Text-based**: data is sent as plain text.
2. **One-way communication**: data flows only from the server to the client. The client can't send data to the server.
3. **Persistent connection**: once a connection is established, the server can keep it open and keep sending data.
4. **Automatic reconnection**: if the connection drops, the client automatically tries to reconnect.

## Implementing SSE in Flask

For a basic SSE implementation, create a Response object and set its `content_type` to **text/event-stream**. **text/event-stream** is the SSE content type, which returns **string data**. The string data the server sends to the client follows **specific rules**. First, here's the format for sending basic data.

1. Start with the string `data:`
2. The string data you want to send
3. Each message must end with a blank line (i.e. `\n\n`).

<div class="file-name">main.py</div>
```python
from flask import Flask, Response
import time

app = Flask(__name__)

def generate():
    while True:
        # DO NOT forget the prefix and suffix
        yield f"data: Hello! {user_id}\n\n"
        time.sleep(5)

@app.get("/connection/<user_id>")
def connection(user_id: str):
    return Response(generator(user_id), content_type="text/event-stream")

if __name__ == "__main__":
    app.run(port=5000)
```

<div class="file-name">js</div>
```js
const eventSource = new EventSource("http://localhost:5000/connection/tiaz");

eventSource.onmessage = function(event) {
    console.log("New event:", event.data);
};
```

## text/event-stream Fields

SSE messages are sent as plain text and are built from a few **special fields**. The main fields are:

### The event Field

Specifies the name of the event. The client can use this name to set up a listener for a specific event type.

```text
event: notice\n
```

### The data Field

Contains the event's actual data. The data can span several lines, and each line must start with **`data:`**. Multiple data lines are joined and handled as one message. If no event is specified, the event is set to `message`.

```text
data: {"userId": 1, "status": "online"}
data: {"additional": "info"}
```

### The id Field

Sets the ID of the last event in the event stream. When reconnecting after a dropped connection, the client can use this ID to request the events it missed.

```text
id: 12345\n
```

### The retry Field

Specifies how long (in milliseconds) to wait before trying to reconnect after the connection drops.

```text
retry: 3000\n
```

These fields can be used on their own or combined.

```text
data: {"userId": 1, "status": "online"}

event: notice
data: {"userId": 2, "status": "offline"}

id: 67890
data: {"message": "Something happened"}

retry: 5000
data: {"retryMessage": "Please wait"}
```

As long as you follow this format, web browsers and clients that support SSE can parse these messages properly and act on them.

## Things to Watch Out for on the Server

For SSE returning **string data**, just follow the format described above. However, if you want to send **JSON data**, you have to **serialize** it into the `data` field so that it becomes a string in the right format.

```python
yield f"""event: notice\ndata: {json.dumps(data)}\n\n"""
```

<div class="file-name">main.py</div>
```python
from flask import Flask, Response
from time import sleep
import json

app = Flask(__name__)

def generator(user_id):
    yield f"data: Hello! {user_id}\n\n"

    while True:
        data = {"name": user_id}
        yield f"""event: notice\ndata: {json.dumps(data)}\n\n"""
        sleep(5)

@app.get("/connection/<user_id>")
def connection(user_id: str):
    return Response(generator(user_id), content_type="text/event-stream")

if __name__ == "__main__":
    app.run(port=5000)
```

<div class="file-name">js</div>
```js
const eventSource = new EventSource("http://localhost:5000/connection/tiaz");

eventSource.onmessage = function(event) {
    console.log("New event:", event.data);
};

eventSource.addEventListener("notice", (e) => {
  console.log(event.data);
});
```

## Wrapping Up

**Server-Sent Events (SSE)** is a **one-way communication** method for sending **string data** from the server to the client. The key to implementing it is building strings in the format the spec requires. Be sure to check the exact format of each field as you write them. 😊
