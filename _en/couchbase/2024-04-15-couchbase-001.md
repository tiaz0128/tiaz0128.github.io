Let's look at how to use **Couchbase**, one of the document-based NoSQL databases.

## Couchbase

![Couchbase](/assets/img/title/Couchbase/Couchbase.webp)

At its core, Couchbase stores documents such as JSON as key-value pairs. Here are its main features in brief:

- Open source
- Key-value store
- Document database
- Supports a SQL-like query language (N1QL)
- Provides a Web Console

## Installation

Follow the [Couchbase installation guide](https://docs.couchbase.com/server/current/getting-started/do-a-quick-install.html#initialize-cluster-web-console){:target="_blank"} to install it. With Docker you can easily run a Couchbase server locally. You can also install it directly, depending on your operating system.

```bash
$ docker run -t --name db -p 8091-8096:8091-8096 -p 11210-11211:11210-11211 couchbase/server:enterprise-7.2.0
```

## Developing with the SDK

Couchbase provides SDKs for many languages. Here we'll look at developing against Couchbase with `python`. The SDK installs easily with `pip`.

```bash
$ pip install couchbase
```

### Connecting to Couchbase

Create an authenticator for connecting to Couchbase and set how long to wait for the `cluster` to be ready.

```python
from datetime import timedelta

from couchbase.auth import PasswordAuthenticator
from couchbase.cluster import Cluster
from couchbase.options import ClusterOptions

username = "Administrator"
password = "password"

auth = PasswordAuthenticator(username, password)

cluster = Cluster('couchbase://localhost', ClusterOptions(auth))

cluster.wait_until_ready(timedelta(seconds=5))
```

### Bucket

You can access a bucket through the `cluster` you created.

```python
bucket_name = "travel-sample"
bucket = cluster.bucket(bucket_name)
```

### Collection

Collections let you group documents by purpose or topic. A collection lives inside a given scope.

The example uses the airline collection in the inventory scope of the Travel Sample bucket.

```python
airline = bucket.scope("inventory").collection("airline")
```

### Inserting a Document: upsert

Let's put a document into the airline collection under the key airline_8091. If the key already has data it's an `update`; otherwise it's an `insert`.

The result includes an integer CAS (Compare And Swap) value. It represents the document's current state and changes every time the document is modified. You can use it to prevent concurrent modifications of the same document.

```python
doc = {
    "type": "airline",
    "id": 8091,
    "callsign": "CBS",
    "iata": None,
    "icao": None,
    "name": "Couchbase Airways",
}

key = doc["type"] + "_" + str(doc["id"])
result = airline.upsert(key, doc)

print(result.cas)
```

### Fetching the Result: get

You can fetch a stored value with `get`. The result's `content_as` property converts the data to whatever type you want.

```python
key = airline_8091
result = airline.get(key)

print(result.content_as[str])
print(result.content_as[dict].get('id'))
```

### SQL++ (N1QL)

You can pull data out of stored documents with a SQL-like query language. Check out the pages below and try writing some SQL++.

- [SQL++ for Query Reference](https://docs.couchbase.com/server/current/n1ql/query.html){:target="_blank"}
- [N1QL Query language tutorials](https://query-tutorial.couchbase.com/tutorial/#1){:target="_blank"}

```python
inventory_scope = self.bucket.scope("inventory")

sql_query = "SELECT VALUE name FROM airline WHERE type = $1 LIMIT 5"

row_iter = inventory_scope.query(
    sql_query,
    QueryOptions(positional_parameters=["airline"]),
)

for row in row_iter:
    print(row)
```

## Wrapping Up

Couchbase is a document-based NoSQL database well suited to storing data like JSON. It stores documents per bucket and lets you manage them efficiently by logically partitioning them into scopes and collections. And with N1QL, its SQL-like query language, you can put the stored documents to use in many more ways.
