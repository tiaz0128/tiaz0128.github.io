## What is MCP (_Model Context Protocol_)?

![MCP](/assets/img/content/ai/001/001.webp)

> The Model Context Protocol (MCP) is an open protocol that enables seamless integration between LLM applications and external data sources and tools. Whether you're building an AI-powered IDE, enhancing a chat interface, or creating custom AI workflows, MCP provides a standardized way to connect LLMs with the context they need.

*> Source: [github - Model Context Protocol](https://github.com/modelcontextprotocol){:target="_blank"}*{:.img-caption}

**MCP (_Model Context Protocol_)** is a protocol proposed by [Anthropic](https://docs.anthropic.com/en/docs/welcome){:.none target="_blank"}, the company behind Claude. Put simply, it's a protocol that lets an LLM pull in extra context through various applications.

It's the technology that lets an LLM use other applications as tools on its own, whenever it needs them.

Plugins already exist that let a huge number of applications connect to the LLM [Claude](https://claude.ai){:.none target="_blank"} through MCP. In this post, we'll connect [Obsidian](https://obsidian.md/){:.none target="_blank"} via MCP.

### Installing Claude Desktop

To connect Claude with MCP, the first thing you need is [Claude Desktop](https://claude.ai/download){:.none target="_blank"} installed on your local machine.

![Claude for Desktop Beta](/assets/img/content/ai/001/002.webp){:.img-s}

`> Claude Desktop`{:.img-caption}

### MCP server for Obsidian

We'll use a Python library called [MCP server for Obsidian](https://github.com/MarkusPfundstein/mcp-obsidian){:.none target="_blank"} to connect Claude and Obsidian over MCP.

## 1. Install the community plugin

First, this MCP server library talks to Obsidian through a REST API. So we need to install the [Local REST API](https://github.com/coddingtonbear/obsidian-local-rest-api){:.none target="_blank"} community plugin, which exposes a REST API for Obsidian.

Go to `Options`{:.path} - `Community plugins`{:.path} - `Browse button`{:.path}, search for the `Local REST API` plugin and install it. Then make sure to enable the plugin.

![Local REST API](/assets/img/content/ai/001/003.webp)

`> Don't forget to enable the community plugin after installing it`{:.img-caption}

Click the ⚙️ button next to the enable toggle to open its settings, and copy the API Key. You'll need it for the MCP configuration.

![Local REST API](/assets/img/content/ai/001/005.webp)

`> Copy the API Key needed for the Claude MCP configuration`{:.img-caption}

## 2. Install Python uv

  type="note"

  url="/python/13"

`uv` is a Python package manager. Follow the [Installing uv](https://docs.astral.sh/uv/getting-started/installation/) page to install it.

<div class="file-name">Linux/Mac</div>

```bash
$ curl -LsSf https://astral.sh/uv/install.sh | sh
```

<div class="file-name">Windows</div>

```bash
> powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Run the command below to check that `uv` was installed correctly.

```bash
$ uv --version
```

```bash
uv 0.6.3 (a0b9f22a2 2025-02-24)
```

## 3. Configure MCP in Claude

1. Launch Claude Desktop and open the `Settings` window.
2. From the hamburger menu at the top left, click `File`{:.path} - `Settings`{:.path}.
3. In that window, select the `Developer`{:.path} tab.
4. Click the `Edit Config`{:.path} button to open the `claude_desktop_config.json` file.

![Local REST API](/assets/img/content/ai/001/004.webp)

`> Open Settings in Claude Desktop`{:.img-caption}

Paste the JSON below into `claude_desktop_config.json`. Finally, replace `<YOUR_OBSIDIAN_API_KEY>` with the API Key you copied from your Obsidian plugin.

<div class="file-name">claude_desktop_config.json</div>

```json
{
  "mcpServers": {
    "mcp-obsidian": {
      "command": "uvx",
      "args": [
        "mcp-obsidian"
      ],
      "env": {
        "OBSIDIAN_API_KEY" : "<YOUR_OBSIDIAN_API_KEY>"
      }
    }
  }
}
```
