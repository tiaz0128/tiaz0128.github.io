## Cursor

![Cursor](/assets/img/content/ai/002/001.webp){:.img-200x200}

Cursor is an AI-powered code editor focused on boosting developer productivity. Because it's built on VS Code, you can migrate your VS Code settings straight over and keep using them.

### Installing Cursor

Download and install Cursor from the [Download Cursor](https://www.cursor.com/downloads){:target="_blank"} page.

## Cursor MCP

Cursor supports MCP out of the box, which makes it quick and easy to connect AI to all kinds of services.

1. Click the `Open Cursor Settings`{:.path} button
2. Select the `MCP`{:.path} tab
3. Configure the MCP servers you want

![Cursor MCP](/assets/img/content/ai/002/002_2.webp){:.img-m}

`> The Cursor MCP tab makes it easy to connect AI to many services`{:.img-caption}

### MCP servers

Here we'll connect two MCP servers.

- [GitHub MCP Server](https://smithery.ai/server/@smithery-ai/github){:target="_blank"}
- [BrowserTools MCP](https://github.com/AgentDeskAI/browser-tools-mcp){:target="_blank"}

## Connecting GitHub

### Smithery

[Smithery](https://smithery.ai/){:.none target="_blank"} is a site that collects MCP servers. There are lots of them, so find the ones you need and give them a try!

![Smithery](/assets/img/content/ai/002/003.webp){:.img-m}

### GitHub MCP Server

Search Smithery for GitHub and click the GitHub server by `@smithery-ai/github`.

![GitHub MCP Server](/assets/img/content/ai/002/004.webp)

### GitHub Token

The MCP server needs a GitHub token to access GitHub.

1. Click `Settings`{:.path} from your GitHub profile
2. Click the `Developer Settings`{:.path} tab (it's at the very bottom)
3. Click `Personal access tokens`{:.path} - `Fine-grained tokens`{:.path} - `Generate new token`{:.path}

![GitHub token](/assets/img/content/ai/002/005.webp)

### Setting Token Permissions and Creating It

{% include template/alert.html
  type="warning"
  about="Copy the token and keep it somewhere safe so it doesn't leak!"
%}

Create the token with the permissions you need, as in the example below.

- Expiration : set the token's expiry
- Repository access : All repositories
- Repository permissions : grant `Read and write` so the features you need will work
  - Actions
  - Administration
  - Commit statuses
  - Contents
  - Issues
  - Commit statuses

### Smithery Installation

{% include template/alert.html
  type="note"
  about="Be sure to check your Cursor version! The setup differs depending on whether you're on Cursor ≥0.47.x!"
%}

1. Click the `Cursor`{:.path} tab under Installation on the right side of Smithery
2. Enter your GitHub token and click `Connect`{:.path}
3. Copy the command for your Cursor version and OS, or copy it as JSON

![Smithery install](/assets/img/content/ai/002/006_2.webp){:.img-m}

### Applying It in Cursor (Cursor ≤0.46.x)

{% include template/alert.html
  type="note"
  about="Depending on the server, you may need to install Docker, Node, Python, etc. Always check the command!"
%}

Now just add the command you copied, and the MCP server setup in Cursor is done!

1. In Cursor's MCP tab, click `Add new MCP server`{:.path}
2. `Name`{:.path} : any name you like
3. `Type`{:.path} : select command
4. `Command`{:.path} : paste the copied command

![Add MCP Server](/assets/img/content/ai/002/010.webp){:.img-m}

### mcp.json (Cursor ≥0.47.x)

{% include template/alert.html
  type="warning"
  about="If the UI popup for adding an MCP server doesn't appear, try configuring it directly in JSON!"
%}

With an `mcp.json` file you can configure which MCP servers run per project or across all projects. See the [Configuration Locations](https://docs.cursor.com/context/model-context-protocol#configuration-locations){:target="_blank"} page for details!

<div class="file-name">.cursor/mcp.json</div>

```json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": [
        "-y",
        "@smithery/cli@latest",
        "run",
        "@smithery-ai/github",
        "--config",
        "{\"githubPersonalAccessToken\":\".............\"}"
      ]
    }
  }
}
```

## Connecting Chrome DevTools

Next, let's set up the [BrowserTools MCP](https://github.com/AgentDeskAI/browser-tools-mcp){:target="_blank"} server, which lets Cursor use the browser's developer tools directly.

### Downloading the Chrome Extension

{% include template/alert.html
  type="note"
  about="This MCP server works with Google Chrome or Chromium-based browsers."
%}

As of now (2025.03.15), the extension is still awaiting approval on the Marketplace. So you have to download the extension as a zip file and install it manually.

Follow the [Installation](https://browsertools.agentdesk.ai/installation){:target="_blank"} page to install it.

### Installing the Extension

1. In Chrome, open `Manage extensions`{:.path}
2. Turn on `Developer mode`{:.path}
3. Load the unpacked extension

![BrowserTools MCP](/assets/img/content/ai/002/009.webp){:.img-m}

### Connecting to Cursor

Now just add the command below, and the MCP server setup in Cursor is done!

```bash
npx @agentdeskai/browser-tools-mcp@1.2.0
```

### Cursor! Check the Chrome Browser Errors and Fix Them

Now, through MCP, Cursor can use Chrome directly to check errors and fix them!
