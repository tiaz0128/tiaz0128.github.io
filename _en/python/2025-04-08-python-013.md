## Introducing uv

![uv logo](/assets/img/content/python/013/002.webp){:.img-s}

uv is a Python package and project management tool built in Rust by Astral. Its biggest advantage is that **installing packages is incredibly fast**{:.orange}.

Take a look at the graph comparing how long `pip` and other package managers take to install the `Trio` Python package, and you'll see just how fast uv is.

![uv speed](/assets/img/content/python/013/001.webp)

*> Source : [Installing Trio's dependencies with a warm cache.](https://docs.astral.sh/uv/){:target="_blank"}*{:.img-caption}

It also helps you manage dependencies more efficiently. It's getting even more attention now that it's officially recommended for MCP (_Model Context Protocol_) development.

## Installing uv

Follow the [Installing uv](https://docs.astral.sh/uv/getting-started/installation/){:target="_blank"} page to install it.

There are two main ways to install it: through an existing package manager, or as a standalone installation.

### Standalone Installation

{% include template/alert.html
  type="note"
  about="If you plan to use it for MCP, I recommend the standalone installation!"
%}

```bash
# On Windows.
> powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

```bash
# On macOS and Linux.
$ curl -LsSf https://astral.sh/uv/install.sh | sh
```

### Installing with an Existing Package Manager

```bash
# With pip.
$ pip install uv

# Or pipx.
$ pipx install uv
```

### Verifying the Installation

Check the uv version with the command below to make sure it installed correctly.

```bash
$ uv --version
```

```text
uv 0.6.3 (a0b9f22a2 2025-02-24)
```

### Updating the Version

You can update uv with the command below only if you installed it as standalone.

```bash
$ uv self update
```

## Key Features of uv

### Installing Python: uv python

With the `uv python` command, you can install whichever Python versions you want in one go.

```bash
$ uv python install 3.12 3.13
```

### Running in a Virtual Environment: uv run

With the `uv run` command, you can run a script while automatically installing any Python version that isn't installed yet and including the packages it needs.

```bash
$ uv run --python 3.10 --with fastapi,pytest main.py
```

- Automatically downloads and installs Python 3.10 if it isn't installed
- Installs the fastapi and pytest packages
- Runs the main.py file

### Virtual Environments: uv venv

`uv venv` creates and manages virtual environments. You can create a virtual environment with a specific Python version. If that version isn't installed, it's installed automatically.

```bash
$ uv venv --python 3.10 .venv
```

## Managing Projects with uv

### Initializing a Project: uv init

The `uv init` command automatically sets up the project structure and generates the basic files you need.

```bash
$ uv init my-app --app --python 3.10
```

```text
└── my-app
   ├── .venv
   ├── README.md
   ├── main.py
   ├── pyproject.toml
   └── uv.lock
```

- `--app`{:.path}: Create a project for an application
- `--python <PYTHON>`{:.path}: Set the minimum supported Python version

If needed, you can also add just a `pyproject.toml` file to an existing project to install and manage packages.

```bash
$ uv init --bare
```

- `--bare`{:.path}: Create only the pyproject.toml file
- `--script`{:.path}: Create a script
- `--package`{:.path}: Set up the project as a Python package
- `--lib`{:.path}: Create a project for a library

### Managing Packages

You can add packages with `uv add`.

- `--extra <EXTRA>`{:.path}: Install the package's optional dependencies (extras)
- `--dev`{:.path}: Add as a development dependency
- `--group <GROUP>`{:.path}: Add the dependency to a specific group

```bash
$ uv add fastapi

$ uv add uvicorn --extra standard

$ uv add ruff --dev

$ uv add pytest --group test
```

<div class="file-name">pyproject.toml</div>

```toml
[project]
name = "my-app"
version = "0.1.0"
description = "Add your description here"
readme = "README.md"
requires-python = ">=3.10"
dependencies = [
    "fastapi>=0.115.12",
    "uvicorn[standard]>=0.34.0",
]

[dependency-groups]
dev = [
    "ruff>=0.11.4",
]
test = [
    "pytest>=8.3.5",
]
```

To remove dependencies, use the `uv remove` command. It takes options similar to `add`.

```bash
$ uv remove fastapi uvicorn
$ uv remove --dev
$ uv remove --group test
```

### Installing and Syncing Packages

If you have a `pyproject.toml`{:.path} file, you can use `uv sync`. Various options let you choose which groups of packages to install.

```bash
# Install all dependencies (default)
$ uv sync

# Install without development dependencies
$ uv sync --no-dev

# Install only development dependencies
$ uv sync --only-dev

# Install including a specific group explicitly
$ uv sync --group test
```

Or you can install packages from `requirements.txt`{:.path} with `uv pip install`.

```bash
$ uv pip install -r requirements.txt
```

Conversely, the `uv export` command turns the currently installed packages into a `requirements.txt` file.

```bash
$ uv export -o requirements.txt
```
