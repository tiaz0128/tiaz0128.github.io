When people hear "Linux," many picture a gloomy black screen filled with white text. When I first ran into Linux, I also found **every single command unfamiliar and overwhelming**.

This book is **a friendly guide for exactly those Linux beginners**{:.orange}. Its tagline, "Linux fundamentals," fits it well.

## Hands-On Structure

The book's biggest strength is its **hands-on structure**{:.yellow}. Rather than just listing commands, it's designed so you pick them up naturally by following along one by one.

### Getting Started Easily with VirtualBox

To learn Linux, you first have to install Linux, and that alone is a big barrier for beginners. This book guides you through using VirtualBox to easily set up a Linux environment even on Windows or Mac.

### Covering Both Ubuntu and Rocky

The book covers two distributions: **Ubuntu** from the Debian family and **Rocky** from the Red Hat family. In real work you can run into both families of Linux, so learning the differences ahead of time helps a lot.

<div class="file-name">Ubuntu</div>

```bash
$ sudo apt update
$ sudo apt install nginx
```

<div class="file-name">Rocky Linux</div>

```bash
$ sudo dnf update
$ sudo dnf install nginx
```

## Step-by-Step Learning

The book is divided into three parts.

### Part 1: First Steps in Linux

It covers **the most basic material**: what Linux is, how to install it, what the basic commands are, and so on. This part also covers the concept of the file system and how paths work.

```bash
# Move using an absolute path
$ cd /home/ubuntu/blog

# Move using a relative path
$ cd ../
```

### Part 2: Putting Linux to Work

Once you have the basics down, it's time to learn the features you'll use often in practice. It covers **must-know material for real work**, such as package management, file compression, and process management.

The **shell script programming** chapter was especially useful. Automating repetitive tasks can boost your productivity a lot.

```bash
#!/bin/bash

cat << END
==========
Select a number ->
==========
1. Check disk usages
2. Check login users
------------------------
END
echo -n "Number : "
read number
case $number in
  1) df -h ;;
  2) who ;;
  *) echo "Wrong number" ;;
esac
```

### Part 3: Real-World Linux Projects

Finally, you pull everything together through **real-world projects**. It offers a variety of hands-on exercises: building a web server, building a file server, using a Raspberry Pi, and even using the cloud (AWS).

The **file server exercise**, where you set up SAMBA and NFS yourself, was especially practical.
