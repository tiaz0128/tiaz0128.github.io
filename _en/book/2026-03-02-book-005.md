## How Writing SQL Has Changed

For developers, SQL has always been a tough homework assignment. Especially when writing queries with several complex `JOIN`s tangled together and subqueries nested inside subqueries, it took a lot of time to **picture the data flow in my head and verify every line**.

I remember once writing a query that had to combine several tables to produce monthly sales totals and month-over-month growth rates in one go. I worked out the entities, sorted out the join conditions, and looked up window function syntax as I went — and ended up pouring hours into that single query.

What about now? **If you describe the table structure and requirements to an AI, you get a draft query back in seconds.**{:.yellow} Even counting the time to review and revise it, it takes less than half as long as it used to.

This book shows how to use AI properly to write SQL more efficiently, in step with the times.

## Better Tools, and the Developer's Role

When you think about it, developer tools have kept evolving. We went from writing code in Notepad to IDEs, then IDEs got autocomplete, and now AI suggests the code itself. SQL is no different.

What matters is that **the essence doesn't change even when the tools do**. Just as understanding the intent of code is still the developer's job even with IDE autocomplete, when AI generates a query, it's ultimately up to a person to judge whether the query is correct and whether it performs well.

The book's core message hits exactly this point.

> "AI can write queries for you, but 'understanding' and 'optimizing' them is still a human job. This book shows you how to accelerate your SQL skills with AI."

## A Three-Step Journey with AI

The book is organized into three Steps, and I was impressed by how naturally each part flows into the next. Beyond how to use AI, it systematically explains the core concepts you need, too.

![Quickstart SQL with ChatGPT](/assets/img/content/book/005/004.webp){:.img-m}

`> It also explains the concepts you need, systematically`{:.img-caption}

### Step 1 | Using AI Smartly

This part really hit home. Vaguely asking **"Write a query that meets these conditions"** versus handing over the table DDL, sample data, and even the shape of the result you want makes a night-and-day difference in the quality of the query the AI gives back. At first I also just tossed off questions, got bizarre queries back, and wasted time repeatedly asking for fixes.

Understanding how ChatGPT works and where its limits are, and learning how to design good prompts, is **essential to using AI well**. This part builds that instinct systematically.

### Step 2 | Hey AI, Write Me Some SQL

You follow along as you write everything from basic `SELECT` statements to `JOIN`s, subqueries, and aggregation and analytic queries together with AI.

1. Present the scenario
2. An example of a suitable prompt
3. The SQL the AI wrote
4. An explanation of the concepts involved

### Step 3 | Hey AI, Tune My SQL

This is the most impressive part of the book. If you've ever responded to a slow query by blindly adding indexes or digging through Google, this part will really resonate.

**It starts with understanding the execution plan.** The book first explains, step by step, how the database optimizer works and what each item in an execution plan means. After that, I learned real-world examples of tuning queries with AI, along with caveats and other useful practical tips.

Asking AI to analyze an execution plan actually struck me as pretty useful. It explains why the optimizer chose a particular path and where the bottleneck is, and even suggests how to improve it.

## Final Thoughts

In an age overflowing with AI tools, if you neglect SQL thinking **"the AI will just write it for me,"** you'll be helpless when the AI hands you a wrong query. In practice, I often run into AI-generated queries that look logically plausible but hide serious performance problems.

Instead of blindly trusting AI or ignoring it, this book shows you **how to use AI properly to raise your actual SQL skills**. Used well, AI can be what takes the way you write SQL up a level.

### What I Missed

Of course, there were some things I wished for. I would have liked a bit more on using MCP (Model Context Protocol) and on how to pass along more context efficiently. Especially on large real-world projects, the amount of information you need to convey becomes enormous, and the book would have been even more practical if it had gone deeper into techniques for distilling that information and feeding it to the AI effectively.

### Recommended For

- Anyone who has learned SQL syntax but isn't confident applying it at work
- Data analysts and engineers who handle large volumes of data but feel shaky on query optimization and tuning
