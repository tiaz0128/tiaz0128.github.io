"3-6" / "1,3-5" / "all". 없으면 재생하지 않고 멈춰 있다 auto : "1" 이면 스스로 재생된다. 기본은 멈춰 있다가 재생 버튼을 눌러야 시작 loop : "1" 이면 마지막 스텝 뒤 처음으로 돌아간다 bare : "1" 이면 툴바·재생 컨트롤 없이 그림만 나온다 ratio : 액자 비율. "16:9"(기본) / "1:1" / "9:16" fit : "1" 이면 각 스텝을 그 스텝이 보여주는 것에 맞춰 다시 담는다. ratio 로 비율을 바꿨을 때 켜라 — 아래 설명 참고 captions : "0" 이면 자막을 그리지 않는다 (본문이 이미 그 이야기를 할 때). 숫자면 그 배율로 그린다 — "1.25" / "1.5" 처럼. 없으면 스토리가 저장해 둔 크기, 그것도 없으면 보는 사람의 기본 설정을 쓴다 height : 높이(px). 주면 ratio 대신 이 높이로 고정된다 (스토리 없는 그림용) title : 그림 아래 캡션. 붙이면 iframe 의 접근성 제목으로도 쓰인다 (선택) ratio 는 이제 액자와 그림을 한꺼번에 정한다. 액자는 아래 CSS 클래스가, 그림은 URL 의 aspect 파라미터가 받는다 — 예전에는 그림 비율이 문서에 저장된 스토리의 Frame 값이라서 둘을 손으로 맞춰야 했고, 어긋나면 가운데에 다른 모양의 창이 뜨는데도 아무도 알려주지 않았다. ratio 를 주지 않으면 스토리가 작성된 그대로 재생된다. captions 가 있는 이유도 같다. 임베드는 작성한 폭의 1/3짜리 액자에서 읽히는데, 거기 그려지는 글씨 크기가 여태 *읽는 사람의* 설정이었다. fit 은 ratio 의 나머지 반쪽이다. ratio 는 액자 모양만 정할 뿐, 그 안에 무엇을 어떻게 담을지는 정하지 않는다 — 스텝의 카메라 이동(pan)은 캔버스 단위로 저장되어 있어서, 같은 숫자가 9:16 화면에서는 1/3, 1:1 에서는 2/3 를 움직인다. 그래서 폰 카드용으로 "자막 위로" 올려둔 그림이 정사각 액자에서는 자막 아래로 깔려버린다. fit="1" 이면 그 이동을 버리고 각 스텝이 보여주는 것을 가운데 담는다 (치트시트의 *그림에 맞추기* 와 같은 규칙). ratio 를 문서의 비율과 다르게 줬다면 대체로 켜는 편이 낫다. 주의: story 를 주지 않으면 지금까지처럼 "멈춰 있는 다이어그램"으로 열린다. 스텝을 지정해도 링크를 직접 연
